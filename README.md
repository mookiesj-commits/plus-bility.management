# +BILITY 통합관리 4차 · 서버형

## 이번 4차 핵심 변경
- **회원정보 메뉴와 회원정보 데이터 모듈을 완전히 제거**했습니다.
- 직원 계정의 프로필 영역을 누르면 **본인 비밀번호 변경**이 가능합니다.
- 관리자도 사용자관리에서 직원 비밀번호를 설정/초기화할 수 있습니다.
- PC와 스마트폰이 **같은 서버 주소**로 접속하여 같은 데이터를 사용합니다.
- 서버는 PostgreSQL을 지원하며, PostgreSQL이 없으면 로컬 JSON 저장으로 실행됩니다.
- 서버에서 데이터 변경 시 SSE(Server-Sent Events)로 접속 중인 다른 화면에 변경 신호를 보내 자동 갱신합니다.
- 직원은 결제/매출만 접근하며 본인이 입력한 자료만 조회/수정/삭제합니다.
- 지출관리는 관리자만 접근합니다.
- 매출은 실제 입력시간(createdAt) 최신순입니다.
- 회원/프로그램 검색만 지원하며 입력자는 검색 대상이 아닙니다.
- 사용자 이름 변경 시 기존 매출의 입력자명과 급여 지출의 직원명이 서버에서 자동 변경됩니다.
- 설정값 변경 시 기존 데이터의 해당 값도 함께 변경합니다.
- 10월 등 미래월 지출도 월별 지출 현황에 포함됩니다.
- 회원정보가 제거되었으므로 Dashboard의 회원 수 카드도 제거하고 결제건 중심으로 표시합니다.

## 기본 계정
- 관리자: `admin / admin1234`
- 직원: `staff01 / 1234`

운영 배포 전 비밀번호를 변경하세요.

## 로컬 실행
Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저: `http://localhost:3000`

Windows에서는 `통합관리_서버실행.bat`을 실행해도 됩니다.

## PC + 스마트폰 공유
### 같은 사무실/같은 Wi-Fi에서 테스트
PC에서 서버를 실행한 뒤 PC의 사설 IP(예: `192.168.0.10`)를 확인합니다. 스마트폰에서 `http://192.168.0.10:3000`으로 접속하면 같은 서버 데이터를 사용할 수 있습니다. Windows 방화벽에서 3000 포트 허용이 필요할 수 있습니다.

### 인터넷에서 어디서나 사용
Render 같은 Node.js 호스팅에 이 프로젝트를 배포하고 PostgreSQL을 연결하세요. `render.yaml` 예시를 포함했습니다. 배포 후 생성된 HTTPS 주소 하나를 PC와 스마트폰에서 같이 사용하면 됩니다.

필수 환경변수:
- `JWT_SECRET`: 긴 랜덤 문자열
- `DATABASE_URL`: PostgreSQL 연결 문자열

## 실시간 동기화
한 사용자가 저장하면 서버의 상태 버전이 올라가고 SSE 이벤트가 모든 접속자에게 전송됩니다. 각 브라우저는 최신 상태를 다시 받아 자동으로 화면을 갱신합니다.

## 데이터
`initial-data.json`은 3차 버전에서 이식된 **결제/매출 및 지출 데이터와 설정값**을 초기 데이터로 사용합니다. 회원정보 배열은 4차 데이터에서 제거했습니다.

원본 Excel에 과거 입력자 정보가 없는 기록은 임의의 직원을 배정하지 않고 기존 입력자 값을 유지합니다.
